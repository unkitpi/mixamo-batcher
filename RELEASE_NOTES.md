# Mixamo Batcher 2.0

Mixamo Batcher 2.0 is a community-maintained Manifest V3 modernization of the original Mixamo Batcher by Faris Mustafa.

## Highlights

- Chrome Manifest V3 support
- CSP-safe communication with the Mixamo page
- XHR and Fetch API interception
- Integrated right-side panel docking
- Entire-pack In Place export
- Per-animation download overrides
- Batch ZIP export for FBX and Collada files
- Local JSON project backup and restore
